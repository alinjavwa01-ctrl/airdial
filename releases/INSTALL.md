# Install AirDial Agent 1.0.0 in Chrome

1. Download `airdial-agent-1.0.0-chrome.zip` and unzip it.
2. Open `chrome://extensions` and turn on **Developer mode** (top right).
3. Click **Load unpacked** and choose the unzipped folder.
4. Pin AirDial Agent from the puzzle-piece menu, then click its icon (or press Alt+A) to open the side panel.

Until the AirDial service is deployed, use Settings › Developer › "Use my own Anthropic API key".

To publish on the Chrome Web Store, upload the same zip at
https://chrome.google.com/webstore/devconsole (needs an AirDial developer account).
